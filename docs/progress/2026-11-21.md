# 系所學術表現分析系統：進度與待辦（2026-11-21）

## 一、目前進度

main 最新 commit：`f096258`（2026-11-14）。11/9～11/14 合併了 PR #2～#9，共 47 個 commit。

### 已完成

**核心功能（第一版，管理學院試辦）**
- 匯入 mapping 表（檢查格式、顯示與上一版差異）、教育部教師數（可逐筆修改）、計畫經費統計表（選填）
- 三份匯入資料重新啟動後會保留
- 透過 Scopus Search、SciVal API 抓資料，計算總篇數、Q1、Top 1%、Top 10%、FWCI、平均被引次數、國際合著，以及各項的師均與排名
- 查無資料或數字異常時標為「待人工確認」，不會當成 0
- 產出：網頁表格、每個系所一份 PPT、每次分析一份 Excel
- 每次分析都保存成一個版本，可以比較兩個版本，並記錄每次用掉的 API 額度
- 首頁流程整合成 7 步；簡報目錄名稱與各頁備註可以在網頁上改

**排除自我引用**
- 算法與 SciVal Publication Set 相同：排除單位論文彼此之間的引用，已和 SciVal 網頁核對過
- 只對「有引用到單位論文」的論文抓參考文獻，節省額度（例如中央財金 145 篇只要查 47 篇）
- 另有「只用 Scopus Search」模式，適合全校分析
- 「設定」可以改成不排除自我引用

**API 與效能**
- 可以設定多組 Elsevier API Key，一組額度用完自動換下一組
- 三支 API 各自限速；遇到 429 會依 `Retry-After` 暫停並降速
- 大批次失敗時自動拆半重試；失敗的單位可以按「繼續」接著抓

**AI 總結（Claude）**
- 在結果頁的「AI 總結」分頁手動按下才會產生（會產生費用），涵蓋每個系所和每個學院
- 有前期資料時加上「與前期比較」，可以手動選要比較的那次分析
- 資料更新後，舊的總結會標成「可能過時」，不會放進簡報
- 產出：系所簡報最後一頁的「總結與建議」，以及全院總結簡報（可打包成 zip）
- 可以選模型（預設 `claude-sonnet-5-5`），也可以在網頁上改提示詞

**安裝與部署**
- Windows 安裝檔（PyInstaller + Inno Setup），不需要裝 Python，也不需要系統管理員權限
- 在系統匣常駐；資料放在 `%LOCALAPPDATA%\ResearchBenchmarking`，升級時會保留
- 系統名稱改為「系所學術表現分析系統」，換上中大 logo

### 尚未合併的分支
- `feat/run-done-go-to-outputs`（11/3）：分析完成後直接跳到產出頁，並防止重複開始分析。首頁流程之後改過，要用的話需要重新 rebase

## 二、研發處新需求（LINE，11/18～11/20）

### 需求 A：打包下載

**背景**：原本想讓各系所主管登入系統查看、填寫修正，但對外開放太麻煩。改由研發處承辦人自己寫信給各主管，**系統負責產出要附的資料**。

**要做的**
- 在產出 PPT 的地方可以下載一個壓縮檔，內容包含：
  1. **Word 信件內容**（範本是「給各位主任所長.docx」）
  2. **要請單位回覆的 Excel**（系統產出，寄給各單位填寫或修正後回傳）
  3. **系統產出的 PPT**
- 另外評估新增一個「下載專區」頁面

**注意**
- Word 內容要經研發長確認，承辦人之後會提供**主管確認版**，所以範本要能替換，不要寫死在程式裡

### 需求 B：AI 分析

承辦人提供了以前做的全校論文分析簡報當參考。

**原則**
- AI 的建議要**建立在量化數據上**；目前系統做好的是量化數據的呈現
- 現在的主管偏好看數據，所以維持表格呈現即可（以前的主管偏好線圖）

**期待 AI 做到的事（依優先順序）**
1. **說明各系所的位置**：贏過哪些學校、被哪些學校超越。只要根據數據說明，不需要到策略分析的程度
2. **從數據中點出問題，寫進簡報**：類似舊簡報上用紅圈標的註解，例如「論文數上升但引用表現下降」「某校快速逼近本校」
3. 至少能對產出的數據做簡單說明
4. **凸顯本校的優勢**
5. 能的話，做「本校現況 vs 競爭學校比較」或「現況/精進 vs 挑戰/機會」這類兩欄對照

**不在範圍內**
- 「各校提升科研成果獎勵措施」這類綜整分析與策略建議：需要其他學校的政策資料，承辦人自己也認為 AI 很難做到

## 三、差距

| 需求 | 目前狀態 | 要做的 |
|---|---|---|
| 一鍵打包 Word、回覆用 Excel、PPT | ❌ 只有 PPT 的 zip，Excel 另外下載 | 產生 Word（依範本填入）、產生回覆用 Excel、合併打包 |
| 下載專區 | ❌ 只有結果頁裡的「下載」分頁 | 評估新增獨立頁面 |
| AI 說明贏過誰、被誰超越 | ⚠️ 只寫整體表現與跟前期比較 | 調整 prompt，把各校排名與差距放進輸入資料 |
| 點出問題、凸顯優勢 | ⚠️ 有，但語氣偏保守 | 跟承辦人確認語氣可以多直接 |
| 兩個五年比較 | ⚠️ 已經可以做（先跑前一期再選它當基準） | 寫進操作說明；受 SciVal「起始年不能早於 10 年前」限制 |
| 現況 vs 挑戰兩欄格式 | ❌ 目前是條列 | 調整 AI 輸出格式與簡報版面 |

## 四、要跟研發處確認的事

1. **壓縮檔怎麼分**：一個系所一包（信、該系所的 Excel、該系所的 PPT），還是全部放成一包？
2. **回覆用 Excel 的內容**：要請各單位確認或修正哪些項目？（例如教師數、對標學校、論文數）
3. **Word 信件的變數**：要不要讓系統自動帶入系所名稱、主管稱謂、回覆期限等？Word 確認版預計什麼時候提供？
4. **AI 語氣**：可不可以直接寫出「被哪些學校超越」？
5. **下載專區**：放在導覽列成為獨立頁面，還是放在每次分析的結果頁裡就好？
